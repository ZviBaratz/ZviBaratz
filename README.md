## I build software for medical imaging.

I came to it through a PhD in neuroscience at Tel Aviv University, where I wrote tools for managing and reading MRI data. Now I'm a Principal Software Engineer at [Quantivly](https://quantivly.com), a healthcare company spun out of Boston Children's Hospital that builds operations software for radiology and MRI. That work is in private repositories, so this page shows what is public: a few open-source projects, and the code and writing from my research years.

Outside work, my interests are terminal workflows, GNOME, and tooling for AI coding agents.

### Open source

**[csa_header](https://github.com/open-dicom/csa_header)**<br>A Python package that parses the CSA headers Siemens MRI scanners store in DICOM files.

**[awesome-dicom](https://github.com/open-dicom/awesome-dicom)**<br>A curated list of DICOM libraries, viewers, datasets and learning resources, which I maintain.

**[hara-hachi-bu](https://github.com/ZviBaratz/hara-hachi-bu)**<br>A GNOME Shell extension that puts power profiles and battery charging thresholds in Quick Settings.

### Research and teaching

**[Predicting Individual Variability From Anatomical Magnetic Resonance Imaging](https://doi.org/10.5281/zenodo.24492985)** · 2023<br>My PhD thesis in neuroscience, Tel Aviv University.

**[dicom_parser](https://github.com/open-dicom/dicom_parser)** · 2020–2023<br>A Python library I wrote during the PhD for reading DICOM headers, built on pydicom.

**[The Labbing Project](https://github.com/TheLabbingProject)** · 2018–2023<br>The Django apps I built during the PhD to manage a lab's MRI research data, described in a [bioRxiv preprint](https://doi.org/10.1101/2023.01.02.522426).

**[Python for Neuroscientists](https://sagol-python-for-neuroscientists.github.io/textbook-public/intro.html)** · 2020–2022<br>The textbook for the Tel Aviv University course of the same name. I'm one of its authors.

In those years I also sent [small fixes](https://github.com/search?q=author%3AZviBaratz+is%3Apr+is%3Amerged+repo%3Anipy%2Fnipype+repo%3Anilearn%2Fnilearn+repo%3Anipy%2Fnibabel+repo%3Apydicom%2Fpydicom+repo%3Anipreps%2Fmriqc+repo%3Anipreps%2Fnireports&type=pullrequests), mostly to documentation and builds, to nipype, nilearn, nibabel, pydicom and MRIQC, and helped set up NiPreps' nireports package in 2022.
